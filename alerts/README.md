# MONO → Telegram

Το GitHub Actions τρέχει το `monitor.mjs` κάθε 15 λεπτά και στέλνει μηνύματα στο Telegram για:

- **βροχή που έρχεται** (έως 3 ώρες πριν) ή βροχή που ξεκίνησε απρόσμενα
- **αλλαγές πρόγνωσης** για σήμερα, αύριο και μεθαύριο: βροχή ±5 mm, πιθανότητα που περνά το 50%, μέγιστη ±3°
- **αλλαγές μοντέλων**: όταν ένα νέο τρέξιμο (ECMWF, ICON, GFS, Météo-France, UKMO, GEM, JMA, ICON-2I, ECMWF AI) αλλάζει τη βροχή κατά ≥ 8 mm ή τη μέγιστη κατά ≥ 4°
- **έντονα φαινόμενα**: ≥ 20 mm τη μέρα, ριπές ≥ 62 km/h, καταιγίδες
- **επίσημες προειδοποιήσεις** Meteoalarm (ΕΜΥ) για την περιοχή
- **πρωινή σύνοψη** (07:00) και **πρόγνωση για αύριο** (21:00)

Τις ώρες 23:00–07:00 τα μηνύματα έρχονται αθόρυβα, εκτός από τις πορτοκαλί/κόκκινες προειδοποιήσεις και τα έντονα φαινόμενα.

## Εντολές στο bot
`/now` καιρός τώρα · `/rain` βροχή 72 ωρών · `/tomorrow` αύριο · `/models` τι λέει κάθε μοντέλο · `/stop` διακοπή · `/start` επανέναρξη.
Οι απαντήσεις έρχονται στον επόμενο έλεγχο (έως ~15 λεπτά).

## Ρύθμιση (μία φορά)
1. Στο Telegram άνοιξε τον **@BotFather** → `/newbot` → δώσε όνομα → πάρε το **token**.
2. GitHub → repo → **Settings → Secrets and variables → Actions → New repository secret**: όνομα `TELEGRAM_BOT_TOKEN`, τιμή το token.
3. Στείλε `/start` στο νέο σου bot.
4. GitHub → **Actions → Telegram alerts → Run workflow** για δοκιμαστικό μήνυμα.

Το πρώτο chat που στέλνει `/start` γίνεται ο παραλήπτης. Για σταθερό παραλήπτη βάλε και secret `TELEGRAM_CHAT_ID`. Για πολλούς, χώρισέ τους με κόμμα.

## Αλλαγές
Όλα ρυθμίζονται στο `config.json`: τοποθεσίες (μπορούν να είναι πολλές), μοντέλα, όρια, ώρες ησυχίας, ώρα σύνοψης.
Χωρίς token το script τρέχει «στεγνά» και γράφει στο log του Actions τι θα έστελνε.
